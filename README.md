# RL Tracker — downloads

Installers and updates for RL Tracker, a second-screen Rocket League stats tracker that reads the game's official Stats API (no mods, works with EAC on).

**Install:** download `RL Tracker Setup <version>.exe` from the latest [release](../../releases/latest) and run it. Windows may say *Windows protected your PC* — click **More info → Run anyway** (the installer isn't code-signed yet).

Installed copies update themselves from this page.
